📖 So funktioniert die DB Quiz-Bahn

Alle Spielregeln auf einen Blick – damit die nächste Runde direkt losgehen kann.

👥Spieler1 bis 4
🏁Spielziel7 vollständige Runden
❓FragetypMultiple Choice
🚦

1. Spielablauf

Reihum beantwortet der aktuell aktive Spieler eine Multiple-Choice-Frage. Bei einer richtigen Antwort fährt die eigene Spielfigur weiter. Bei einer falschen Antwort bleibt die Spielfigur stehen; die nächste Chance gibt es erst, wenn der Spieler wieder an der Reihe ist.

🤖

2. Einzelspieler-Modus

Im Einzelspieler-Modus trittst du gegen 3 NPC-Spieler an. Die NPCs beantworten ihre Fragen automatisch und führen ihre Züge selbstständig aus.

NPC-Schwierigkeiten

  • 🟢 Leichtca. 55 % richtige Antworten
  • 🟡 Mittelca. 72 % richtige Antworten
  • 🔴 Schwerca. 88 % richtige Antworten
📝

3. Richtige und falsche Antworten

  • ✓Richtig: Der Zug wird entsprechend der Frage weiterbewegt.
  • ×Falsch: Die Spielfigur bewegt sich nicht. Es gibt keinen weiteren Versuch im selben Zug.
🍾

4. Flaschen-Regel

Wer 4 Fragen ohne eine Flasche beantwortet hat, erhält einmalig die Möglichkeit, einen anderen Spieler auf START zurückzuschicken. Die verfügbare Fähigkeit wird im Spielerfortschritt angezeigt.

🚧

5. Bahnübergänge

Bei einer Bahnübergangsstörung erscheint eine Zusatzfrage. Dafür stehen 60 Sekunden zur Verfügung. Bei falscher Antwort oder Ablauf der Zeit tritt die jeweilige Störung ein.

⭐

6. Ereignisfelder

Auf Ereignisfeldern können zufällige Ereignisse ausgelöst werden. Die Auswirkungen werden direkt im Spiel angezeigt.

🏅

7. Punktesystem

  • ✅ Richtige Antwort+2 Punkte
  • ❌ Falsche Antwort−1 Punkt

🌟 Die Punkte werden unabhängig von Runden und Feldern im Scoreboard angezeigt.

🏆

8. Spielende

Wer zuerst 7 vollständige Runden erreicht, gewinnt das Spiel. Durch Ereignisse kann ein Spieler dabei auch in einen negativen Rundenstand geraten.
